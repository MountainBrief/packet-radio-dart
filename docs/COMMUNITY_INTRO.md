# Community introduction — draft, not sent

Mountain Brief Foundation is preparing **MB Packet Radio**, a small Apache-2.0
Dart toolkit for developers working on packet-radio and emergency communications
software.

It provides KISS framing and a documented AX.25 modulo-8 frame-codec subset,
with bounded stream parsing, binary payload handling, tests and an offline
example. It works independently of Flutter and MB Cloud.

We would welcome feedback from packet-radio developers, particularly minimal
wire examples and TNC compatibility reports. This first version focuses on
codecs; connected sessions and transport adapters are follow-on work.

Source and quickstart: https://github.com/MountainBrief/packet-radio-dart

This post is ready to adapt after the public release. It has not been sent to
any person or group.
