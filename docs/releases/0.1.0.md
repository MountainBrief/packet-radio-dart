# MB Packet Radio v0.1.0 — developer preview

Reusable Dart building blocks for packet-radio applications, extracted from
Mountain Brief and prepared for community stewardship through Mountain Brief
Foundation. The package has no runtime dependencies outside the Dart SDK.

## Included

- KISS encoding and bounded incremental decoding across arbitrary transport
  fragments, including escaping of port/type bytes and binary payloads.
- A strict AX.25 modulo-8 frame-codec subset: I, RR/RNR/REJ and
  SABM/UA/DISC/DM/FRMR/UI, with source/destination addresses and P/F bits.
- Configurable receive bounds, malformed-frame recovery and immutable payloads.
- An offline example, independent wire fixtures, adversarial-input tests,
  source provenance and contribution instructions.

## Try the example

```sh
git clone https://github.com/MountainBrief/packet-radio-dart.git mb-packet-radio-dart
cd mb-packet-radio-dart
dart pub get
dart run example/mb_packet_radio_example.dart
```

The example encodes a synthetic packet, splits the KISS bytes into small chunks
and decodes it again, entirely offline. See README.md for local dependency setup.

## Scope

This is a developer preview of frame codecs. It does not include a complete
AX.25 session engine, digipeater paths, modulo-128, HDLC FCS, Bluetooth discovery,
TNC sockets, modulation or RF delivery. No live-radio interoperability claim is
made by the offline tests. Publication on pub.dev is deferred.

## Feedback wanted

Useful contributions include minimal synthetic wire fixtures, parser edge cases,
transport-adapter ideas and compatibility reports that identify the exact TNC
and software used. Preserve privacy when sharing captures; follow SECURITY.md
for potential vulnerabilities.
