# MB Packet Radio v0.1.0 — developer preview

KISS framing and a documented AX.25 modulo-8 frame-codec subset for Dart tools
and Flutter projects. The library uses only the Dart SDK.

## Included

- KISS encoding and bounded incremental decoding across transport fragments.
- Escaped port/type and binary payload bytes, with strict malformed-frame recovery.
- Source/destination addresses and I, RR/RNR/REJ, SABM/UA/DISC/DM/FRMR/UI codecs.
- Configurable limits, immutable payloads, independent wire fixtures and an
  offline example.

## Quickstart

```sh
git clone https://github.com/MountainBriefFoundation/packet-radio-dart.git
cd packet-radio-dart
dart pub get
dart run example/mb_packet_radio_example.dart
```

See [README.md](../../README.md) for usage and the supported profile, and
[validation](../VALIDATION.md) for the software checks.

This preview focuses on frame codecs. Connected sessions, digipeater paths,
modulo-128, FCS, transport adapters and RF modulation are outside its scope.
Live-radio interoperability has not been qualified.
